# Phase 5D — TEW Companion Core Mode and Quick Segment Workbench

Phase 5D narrows the everyday experience around the original product goal: **Total Extreme Wrestling IX remains the complete game**, while this browser companion handles custom match approaches, Match Stories, Angle Segment Outputs, assisted TEW entry, and read-only result reconciliation.

## Companion Core navigation

The normal top-level workflow is now:

1. **Show Operations** — card readiness, handoff state, TEW-entry progress, and next action.
2. **Match & Angle Workbench** — standalone Quick Matches and Quick Angles or an existing planned-show running order.
3. **TEW Entry** — the existing assisted field-by-field transfer package.
4. **Results** — post-show read-only result intake and controlled reconciliation.

Championships, competitions, storylines, worker profiles, formula inspection, database research, and the full planned-show editor remain available through **Advanced Tools**. They are not deleted, but they no longer dominate daily use.

## Quick Match and Quick Angle

A Quick Segment does not require a complete tracker-side show.

Quick Matches support participants and sides, duration, match type, match aim, planned winner, finish, title stakes, the existing approach-selection engine, stamina and pace analysis, Match Story generation, key moments, and TEW-ready notes.

Quick Angles support participants and roles, location, content type, purpose, consequences, follow-up, audience takeaway, Angle Segment Output generation, and TEW-ready notes.

The standalone record remains independent when a linked copy is added to a planned show.

## Unified planned-show workbench

The planned-show mode uses a practical three-column arrangement:

- Running order
- Segment setup and approach tools
- Generated output, TEW notes, and draft history

The full Planned Shows editor remains available in Advanced Tools for card-level data that is not part of the everyday approach-and-output workflow.

## Templates and draft history

Built-in structures include:

- Television Opening Promo
- Post-Match Confrontation
- Championship Contract Signing
- Squash Match
- Technical Showcase
- Heated Grudge Match
- Tournament Match
- Tag-Team Showcase
- Main-Event Title Match

Templates supply structure only. They do not choose wrestlers, winners, or dialogue.

Quick Segments preserve named output revisions. A revision can be restored, duplicated into a new standalone segment, or copied as TEW notes without overwriting earlier drafts.

## Worker-rating provenance

Every rating source is designed to be labeled as one of:

- Imported from TEW
- Mapped from TEW
- Derived
- Manual Override
- Missing

The current normalized read-only TEW reader exposes worker identities but does not expose verified match-rating columns. Phase 5D therefore labels those values **Missing** unless a tracker-side profile supplies a clearly marked Manual Override. It does not guess TEW ratings.

## Backup version 15

Version 15 backups include:

- Quick Matches and Quick Angles
- Output revision histories
- Built-in and custom templates
- Rating-source records
- Workbench preferences
- Advanced Tools visibility
- Recent-segment history
- All version 14 and earlier data

Backup versions 1 through 14 remain importable.

## Safety boundary

- No MDB or ACCDB writing
- No modification of a live TEW save
- No replacement match simulator
- No contracts, finances, company simulation, or AI wrestling world
- TEW remains authoritative for actual winners, results, ratings, contracts, finances, and world simulation
