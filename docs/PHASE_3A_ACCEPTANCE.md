# Phase 3A Acceptance — Storyline Hub and Timeline

## Storyline records

- Create, edit, duplicate, filter, and delete tracker storylines.
- Preserve premise, conflict, motivations, beginning, climax, ending, aftermath, and private notes.
- Store status, dates, current phase, and linked championship.

## Participants and links

- Add imported TEW workers or manual participants.
- Assign creative participant roles.
- Attach imported TEW storyline records.
- Attach storyline references already used on planned matches and angles.
- Detect exact-name segment references automatically.

## Timeline

- Include linked planned and reconciled matches and angles.
- Sort entries chronologically.
- Display planned narrative, final narrative, TEW result, rating, consequences, and follow-up.
- Open the related planned show and scroll to the segment.

## Milestones

- Add all supported milestone types.
- Assign milestones to planned shows.
- Track Unassigned, Assigned, Completed, Delayed, and Cancelled states.

## Continuity

- Warn about missing future follow-up.
- Warn about overdue milestones.
- Warn about missing or stale participants.
- Warn about missing aftermath.
- Warn when previously linked segments or assigned shows are deleted.
- Warn about unfinished payoff matches or climaxes.

## Persistence and compatibility

- Autosave storylines in browser storage.
- Export version 4 backups containing shows and storylines.
- Import version 1, 2, 3, and 4 backups.
- Preserve all Phase 1 through Phase 2C workflows.
- Never write to TEW MDB/ACCDB files or modify the TEW executable.

## Automated verification

- Unit tests cover timeline matching, ordering, reconciliation data, milestones, warnings, persistence, and backup migration.
- Browser tests cover storyline creation, timeline display, persistence, existing planner workflows, and MDB compatibility shims.
